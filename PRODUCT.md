# BrightForge — Product Context

## Product
BrightForge: hybrid AI coding + design + 3D generation agent for developers who ship.

## Register
product

## Users
- Indie developers working solo or in small teams (2–5 people)
- Game developers using the Forge3D pipeline for asset creation
- Future public release — the tool will be used by people we haven't met yet

## Product Purpose
Plan, review, and apply code changes using local LLMs with cloud fallback. GPU-accelerated 3D mesh generation from text or image. Multi-provider image generation pipeline. The entire loop — from prompt to diff to disk — stays in one place.

## Personality
Powerful, opinionated, fast. The tool has a point of view. It doesn't ask twice. It respects the developer's time above everything else.

## Tone
Direct. No ceremony. No marketing language. Output is the point, not the experience of using the tool.

## Anti-references
- Generic SaaS dashboards (Notion clones, Vercel-style landing pages)
- Hero-metric templates (big number, small label, gradient accent)
- Identical card grids (icon + heading + paragraph, repeated 6 times)
- Glassmorphism used decoratively
- Blue-as-default because "developer tools are blue"
- Friendly/playful AI assistant aesthetics (rounded corners everywhere, pastel accents)

## Strategic Principles
- Speed and feedback loops over ceremony — every interaction should feel instant
- Local-first (Ollama), cloud as fallback — never vendor-locked
- The tool gets out of the way; the work is what matters
- One surface, not a product suite — everything lives in the dashboard
- Honest status — errors shown plainly, not hidden behind spinners

## Core Features (for design context)
- Chat panel: LLM plan generation with colored diffs, approve/reject flow
- Forge3D: text-to-mesh and image-to-mesh with queue management
- Design engine: multi-provider image generation
- Pipeline agents: planner → builder → tester → reviewer
- Model intelligence: scan local AI models, smart routing
- Orchestration: multi-agent task management
- Security, debug, playtest, scene, world, gameplay panels
